# Viyan R&D, وب‌سایت معرفی تیم

وب‌سایت ایستا و دوزبانه (فارسی/انگلیسی) برای معرفی تیم سه‌نفره Viyan R&D. فقط HTML، CSS و JavaScript خالص؛ بدون Build و بدون وابستگی. فقط فونت‌ها از Google Fonts بارگذاری می‌شوند و در صورت نبودن، فونت جایگزین سیستم نمایش داده می‌شود.

## اعضا

سینا یگانه فعال، علی معینی، بهراد کبیری سامانی

## قابلیت‌ها

- تم تیره و روشن با ذخیره انتخاب (`localStorage`)
- تغییر زبان FA/EN با `lang` و `dir` درست
- رزومه هر عضو در دیالوگ دسترس‌پذیر (`<dialog>`): بستن با Esc، کلیک روی پس‌زمینه، بازگشت فوکوس
- منوی موبایل، ظاهر ریسپانسیو، احترام به `prefers-reduced-motion`

## ساختار

```
index.html
favicon.svg
.nojekyll
assets/css/style.css
```

## اجرای محلی

فایل `index.html` را در مرورگر باز کنید، یا در پوشه پروژه این را اجرا کنید:

```
python3 -m http.server 8000
```

## استقرار در GitHub Pages

حالت اول، مخزن شخصی با نام `username.github.io`:

1. مخزنی با همین نام بسازید.
2. همه فایل‌ها را در ریشه مخزن push کنید.
3. در Settings > Pages، گزینه Deploy from a branch و شاخه `main` و پوشه `/ (root)` را انتخاب کنید.
4. آدرس: `https://username.github.io/`

حالت دوم، مخزن پروژه (مثلاً `viyan`):

1. مخزن را بسازید و فایل‌ها را push کنید.
2. همان تنظیمات Pages را انجام دهید.
3. آدرس: `https://username.github.io/viyan/`

مسیرهای پروژه همه نسبی هستند (بدون `/` ابتدایی)، پس در هر دو حالت کار می‌کنند. اگر CSS یا تصویر 404 داد، مطمئن شوید پوشه `assets` کنار `index.html` است و مسیرها با `/` شروع نشده‌اند. فایل `.nojekyll` را نگه دارید.

## تغییر اطلاعات

- متن‌ها و رزومه‌ها: فقط `assets/js/data.js`. هر متن به شکل `t("English", "فارسی")` است.
- افزودن عضو: یک شیء جدید شبیه اعضای فعلی به `SITE.members` اضافه کنید.
- عکس عضو: فعلاً آواتار حروف اول نمایش داده می‌شود. برای افزودن عکس، فایل را در `assets/img/` بگذارید و در `renderMembers` داخل `main.js` به‌جای آواتار یک `<img>` قرار دهید.
- لوگو: `assets/img/logo.webp` و `logo-mark.webp` را جایگزین کنید. بهتر است نسخه SVG یا PNG شفاف تهیه شود.
- فرم تماس: در `data.js` مقدار `team.email` را با ایمیل واقعی تیم پر کنید تا فرم نمایش داده شود.
- لینک‌های شبکه اجتماعی تیم: در `team.socials` اضافه کنید تا در فوتر نمایش داده شوند.
